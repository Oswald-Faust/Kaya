# Building the identity

1. Name + idea in one sentence. Three principles (e.g. clear before clever, proof over promises, playful never silly).
2. Mark: a simple geometric metaphor of the product (Kaya: three rising clay pills on an ink tile). SVG with 3-stop linear gradients so it reads as clay. Wordmark lowercase, semibold, −5% tracking.
3. Palette: Ink #0B0B0B, White, Cream #F7F5F0, Stone #EDEAE3, Muted #5F5B54; accents each with base / soft / deep:
   Lime #D4F36B/#F3FBD6/#56700F · Blue #4D78FF/#EAF0FF/#2240B0 · Tangerine #FF7A3D/#FFF0E7/#B0450F · Grass #3DA863/#E8F6EC/#1C653A · Lilac #9C80FF/#F1EDFF/#5636BF · Sun #FFC83D/#FFF7DC/#8A6000 · Pink #FF8FC0/#FFEEF5/#B23A70.
   Map each accent to one product idea and keep it consistent across pillars, tabs, menu tiles and plans.
4. Type: pick from a live side-by-side sheet (Host Grotesk, Funnel Display, Bricolage, Schibsted, Inter Tight, Onest). Host Grotesk is closest to Clay's Roobert. Mono: Geist Mono.
5. Illustration style: soft matte clay, top-left light, one idea per scene, on its accent tint; each has a meaningful loop.
6. Publish `/brand` (logo on 4 grounds, sizes, don'ts, swatches with roles and contrast rules, type scale, illustration gallery, UI atoms, voice do/don't) and `docs/brand.md`.
